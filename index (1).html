Turn a URL or text into a cut-ready QR decal file for the Graphtec CE6000-60+

Overall cut width/height. Module size is worked out from this automatically.

Match this to the STEP SIZE set on the plotter's control panel. 40 steps/mm = 0.025mm resolution (Graphtec default).

Sending the file to the plotter

This tool doesn't talk to the CE6000-60+ directly yet — it produces a .gpgl file of raw GP-GL cut commands. Send it to the plotter with whatever's already driving it (Cutting Master, Graphtec Studio's "send file" option, or a raw copy to the printer port). Confirm the plotter's command mode is set to GP-GL on its control panel, and that the STEP SIZE there matches the resolution set above. Run one small test cut before committing a full sheet of vinyl — coordinate scale and origin can vary by driver setup.

QR Cut — v1 (file export). Direct plotter connection from the browser is a planned next step.
