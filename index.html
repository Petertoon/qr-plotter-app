How to cut

  1. Generate the SVG here.
  2. Download the SVG.
  3. Open/import the SVG in Graphtec Studio 2.
  4. Select your CE6000 Plus / CE6000-60.
  5. Check the displayed physical size before cutting.
  6. Send the job from Graphtec Studio 2.

This version has no direct printer output, no PowerShell sender, and no GP-GL download.
